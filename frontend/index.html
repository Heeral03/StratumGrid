About The System

The Problem Solved

The Challenge

Spatial Resource Contention

In high-throughput fulfillment centers, Autonomous Mobile Robots (AMRs), robotic pickers, and human auditors frequently request simultaneous access over physical warehouse sub-grids.

  • Uncoordinated spatial access causes physical robot collisions
  • High contention delays during peak picking schedules
  • Stale locks remain held indefinitely if a bot crashes
The StratumGrid Solution

Hierarchical $O(h)$ Tree Locking & Heartbeats

StratumGrid models the facility as an M-ary tree structure. Ancestor parent pointers and descendant counters validate access in $O(h)$ time, while 30s TTL heartbeats guarantee automatic crash recovery.

  • $O(h)$ constant-time lock validation bound by tree depth
  • Thread-safe pessimistic mutex isolation preventing race conditions
  • Automatic 30s lease expiration when heartbeat pulses stop
